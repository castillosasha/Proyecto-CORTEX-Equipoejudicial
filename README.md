## 📌 Descripción del Proyecto
Este proyecto documenta el diseño de un **Agente de IA** especializado en **cobranzas pre-ejecutivas** para un estudio jurídico ubicado en la ciudad de Buenos Aires, cumpliendo las leyes de la República Argentina.

El agente actúa como la **última instancia de negociación** antes de que un caso pase a cobro ejecutivo por vía legal.

---

## 🎯 Nuestro Agente: "El Ejecutor de la Decisión Final"

### Misión
> *"Cerrar acuerdos de pago en la última instancia antes del cobro ejecutivo, o documentar la negativa del deudor para fortalecer el proceso judicial."*

### Propósito Estratégico
Ser la última oportunidad de diálogo para el deudor, ofreciéndole una salida digna y pactada antes de que el estudio jurídico active la vía ejecutiva.
